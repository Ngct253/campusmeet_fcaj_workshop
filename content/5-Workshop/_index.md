# Building and Deploying CampusMeet on AWS

This workshop explains how CampusMeet is built and deployed on AWS, from architecture, authentication, and data to the core product flow, production frontend, AI integration, and end-to-end verification.

The focus is on **how the system works and how it is deployed**, not on documenting every internal key, route, or unit test.
