### Week 1 Objectives

- Become familiar with the AWS Management Console and selected core AWS services.
- Learn how to create and manage an AWS Free Tier account.
- Practice managing access permissions, networking resources, and virtual servers.
- Learn how to monitor costs, observe resources, and clean up AWS resources after each exercise.
